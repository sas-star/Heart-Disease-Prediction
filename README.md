# 🫀 Heart Disease Prediction

A data analysis and visualization project built using Python,
as part of my learning from the Udemy course 
"Python for Data Analysis & Visualization".

---

## 📌 Objective
To analyze patient health data and identify key patterns
that indicate the risk of heart disease.

---

## 🛠️ Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 What I did
- Loaded and explored the heart disease dataset
- Cleaned and preprocessed the data
- Performed Exploratory Data Analysis (EDA)
- Created visualizations to find patterns
